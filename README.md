# Mint Mate AI

Mint Mate AI is a personal finance assistant built with Java, Spring Boot, and Spring AI. The project explores how to build practical AI-powered applications that can understand financial transaction data and answer questions about personal spending.

## Project goals

Mint Mate AI will evolve from a simple transaction management application into an AI-powered personal finance assistant.

### Planned capabilities include:

- Ask questions about income, expenses, and spending habits using natural language.
- Analyse spending by category, merchant, and time period.
- Identify spending patterns and unusual expenses.
- Compare spending across different months.
- Get insights into savings and financial habits.

## Tech Stack
### Core application
- Java 21 / Spring Boot 4.1
- PostgreSQL persistence with JPA
- Liquibase for database migrations and reference data.
- Docker Compose for local PostgreSQL
- Datafaker for generating realistic sample transactions

### AI and LLM integration
- Spring AI – AI integration and application orchestration.
- Ollama – Run large language models locally without requiring a cloud AI API.
- ChatClient – Interact with language models.
- Structured Output – Convert LLM responses into structured Java objects.


## Local setup

1. Start PostgreSQL:

   ```bash
   docker compose up -d
   ```

2. Provide the required database environment variables:

   ```bash
   export POSTGRES_DB=<provide-detail>
   export POSTGRES_USER=<provide-detail>
   export POSTGRES_PASSWORD=<provide-detail>
   ```

3. Run the application:

   ```bash
   ./mvnw spring-boot:run
   ```

## Seed data

- Categories are created by Liquibase.
- Sample transactions are generated by Datafaker on application startup.
- Transaction seeding can be disabled with:

  ```bash
  mint-mate.seed-transactions.enabled=false
  ```

## Tests

Run the test suite with:

```bash
./mvnw test
```
